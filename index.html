Simulation model / caveats

The operation loop is simulated on the same 1/60-second logical timer used by the shipped client. Cell attack progress, projectile travel, Amoeba weakening stacks, Organelle speed, Fever, Critical Condition square-by-square deaths, Immunoid aggro, Steroid timing and revives are modeled as timed events. Each boss hit randomly selects one living occupied square (or one living Immunoid square while any remain). A hit kills only that square; the rest of a multi-square shape remains. The shape keeps attacking until its anchor/core square is dead, matching the shipped client.

When you paste a full export, the model reads the account-wide Jelly damage inputs directly too: Gaming Palette, Research Grid Cellular Warfare, its Observation multiplier, companion/Dream/Sushi Grid multipliers, and the Jelly upgrade stack. A data-only export remains exact while Cellular Warfare is level 0; later, use the full export so companion bonuses are present. “Observed current clear” is optional validation/override, not the default source of truth.

Random initial attack progress and Critical Condition target selection are Monte Carlo simulated, so the optimizer compares clear probability and clear-time distributions instead of one fake-perfect DPS number. If Stronkroid is unlocked, the solver also searches when to press it during the operation.
