Privacy & analytics

Optional cloud sync signs into Idleon’s Firebase services and reads your account’s cloud save, character names, companions, guild information, and server settings. Email credentials are sent directly to Firebase Authentication. Steam sign-in happens on Steam’s website; the pasted redirect is exchanged directly with Idleon’s sign-in service. The planner does not send these credentials or your save to a planner backend or analytics.

Firebase libraries are loaded from Google’s CDN when you connect. Firebase keeps authentication tokens in browser session storage for this tab, including reloads. The planner clears password and Steam redirect fields after submission and never stores them itself. Disconnect stops updates and signs out, while keeping the displayed save in memory. The existing save-preservation checkbox separately controls whether a save copy survives a tab reload. Your existing local notes, goals, and import comparison summaries remain in browser storage.

Your imported save is processed in your browser. The planner’s analytics integration does not send save contents, character names, pasted text, or error messages to Umami.

When configured, Umami receives anonymous page visits, selected action outcomes, generic error counts, browser language, screen size, referring website origin, and estimated active time. Requests also expose your IP address to the analytics service as part of normal internet communication. No account identifier or session recording is enabled by this integration.

Active time is estimated while the tab is visible and within one minute of interaction. It is not an exact measure of attention. Analytics honors Do Not Track and Global Privacy Control.
